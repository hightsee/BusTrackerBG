# BusTrackerBG

BusTrackerBG is a map-first web app for Belgrade public transport.

Open the app:

```text
https://bustracker.gifted3.com
```

## What It Does

- Search Belgrade stops by name, station number, or address.
- Use your location or pick a point on the map to find nearby stops.
- Check upcoming scheduled departures for each stop.
- Plan routes between stops, including routes with walking links and transfers.
- Save favorite stops and optional line presets after creating an account.
- View route paths and stop sequences directly on the map.

## How To Use It

1. Open the app on your phone or desktop.
2. Use the home search, map, or location button to find a stop.
3. Open a stop to see its lines and next departures.
4. Use the Routes tab to choose a start and destination.
5. Save frequent stops from the stop page or route results.

Location access works best from the HTTPS URL above. Your browser will ask for permission before sharing location.

## Notes

The app uses official GTFS schedule data with local corrections where available. It is schedule-based, not live vehicle tracking.
